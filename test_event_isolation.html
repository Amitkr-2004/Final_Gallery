🧪 Event Isolation Test Helper

This tool helps you test that event-based photo and collection isolation works correctly.

Step 1: Create Migrated Event

First, create the migrated event to access your existing 34 photos.

Step 2: Check Backend Statistics

Verify the migrated event has correct counts from backend.

Step 3: Create New Test Event

Create a new event for testing isolation.

Step 4: Verify Event Isolation

Check that each event shows only its own photos and persons.

Step 5: Open App & Test UI

Open the app and verify the UI shows correct event-specific data.

What to verify in the app:
1. My Events page shows both events
2. Migrated Photos: 34 images, ~60 persons
3. Test Event: 0 images, 0 persons (until you upload)
4. Collections in each event show different persons
5. Photos in each event show different images
